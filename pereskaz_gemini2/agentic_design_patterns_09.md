### Автоматический выбор моделей (Dynamic Model Switching) · Настраивайте систему так, чтобы направлять простые запросы дешёвым и быстрым языковым моделям, а сложные задачи — ресурсоёмким моделям · Пример из текста: маршрутизация простых запросов на Gemini Flash, а сложных задач — на Gemini Pro · (стр. 257)

### Последовательный фоллбек моделей (Sequential Model Fallback) · Указывайте иерархический список моделей на случай сбоев, ограничения лимитов или фильтрации контента, чтобы система автоматически переключалась на резервную модель · Пример из текста: `["anthropic/claude-3.5-sonnet", "gryphe/mythomax-l2-13b"]` · (стр. 256)

### Контекстная прунинг и суммаризация (Contextual Pruning & Summarization) · Сокращайте объем обрабатываемых данных в промпте и снижайте затраты на инференс путём интеллектуального суммирования и отбора только релевантной информации из истории · Пример из текста: удаление лишнего контекста для предотвращения вычислительных затрат · (стр. 257)

### Использование закона масштабирования инференса (Scaling Inference Law) · Выделяйте больше вычислительного времени и шагов («бюджет на мышление») модели во время инференса, чтобы небольшая модель превосходила более крупную · Пример из текста: генерация нескольких вариантов ответа с последующим выбором оптимального · (стр. 278)

### Цепочка мыслей (Chain-of-Thought, CoT) · Заставляйте агента разбивать сложные задачи на последовательные промежуточные шаги вместо выдачи прямого ответа · Пример из текста: пошаговый план из 5 пунктов: анализ запроса, формулировка поиска, симуляция извлечения, синтез, проверка · (стр. 263)

### Дерево мыслей (Tree-of-Thought, ToT) · Позволяйте модели исследовать несколько путей рассуждения с ветвлением, возвратом назад (backtracking) и исправлением ошибок · Пример из текста: построение древовидной структуры возможных траекторий решения задачи · (стр. 266)

### Самокоррекция и самоочистка (Self-Correction) · Встраивайте цикл критической оценки агентом собственных результатов на соответствие исходным требованиям перед выдачей финального ответа · Пример из текста: агент проверяет черновик на точность, полноту, тон и наличие призыва к действию · (стр. 267)

### Программно-поддерживаемые языковые модели (PALM) · Разгружайте агента, поручая точные вычисления, логику и манипуляции с данными детерминированной среде выполнения кода · Пример из текста: использование встроенного исполнителя кода Python для точных расчетов · (стр. 270)

### Цикл «Рассуждение и действие» (ReAct) · Объединяйте внутренний монолог (мысль) с выполнением внешних действий (инструментов) и анализом полученных результатов · Пример из текста: итеративный цикл Thought -> Action -> Observation -> Thought при работе с поиском · (стр. 271)
