### Анализ логов · Уделяйте особое внимание сообщениям в логах, начинающимся с `WARNING`, так как они часто указывают на первопричину сбоев в работе VPN · `WARNING: normally if you use --mssfix and/or --fragment, you should also set --tun-mtu 1500 (currently it is 1400)` · (стр. [нет номера, нач. текста])

### Проверка конфигурации PUSH · Проверяйте полученные от сервера параметры после подключения, сверяя их с ожидаемой конфигурацией · `PUSH: Received control message: 'PUSH_REPLY,route-gateway 10.200.0.1,topology subnet...'` · (стр. [нет номера, нач. текста])

### Настройка логирования через syslog · Используйте директиву `syslog [name]` вместо `log-append` для отправки логов в syslog, что полезно при запуске нескольких экземпляров OpenVPN · `syslog [name]` · (стр. [нет номера, нач. текста])

### Пошаговая диагностика маршрутизации · Начинайте поиск проблем с маршрутизацией изнутри наружу: от проверки связи между VPN-эндпоинтами до пингов между хостами в удаленных локальных сетях · `First, make sure the VPN endpoints can see each other.` · (стр. 86)

### Диагностика с явным указанием исходного IP · Используйте принудительное указание исходного IP-адреса (`ping -I`), чтобы локализовать проблемы с некорректным выбором источника пакетов · `[server]$ ping -I 10.198.0.10 -c 2 192.168.4.66` · (стр. 87)

### Маскарадинг (NAT) для обхода маршрутов · Используйте правила маскарадинга (`iptables MASQUERADE`) как быстрое решение для скрытия диапазонов VPN-адресов, если нет возможности изменить настройки шлюзов, учитывая при этом минусы потери информации о клиентах · `iptables -t nat -I POSTROUTING -i tun0 -o eth0 -s 10.200.0.0/24 -j MASQUERADE` · (стр. 87)

### Использование исходной маршрутизации (Source routing) · Применяйте инструменты вроде `iproute2` для настройки source routing на серверах с несколькими интерфейсами, чтобы входящий и исходящий трафик VPN шли через один и тот же интерфейс · `Source routing is typically used whenever a server is connected to a network (or the Internet) using two network interfaces` · (стр. 88)
