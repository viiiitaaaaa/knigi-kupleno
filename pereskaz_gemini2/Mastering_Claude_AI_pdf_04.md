### Выбор первого языка программирования · Попросите Claude подобрать язык под ваши задачи с помощью промпта: «Я хочу научиться программировать для [ваша цель]. С какого языка мне начать?» · Пример: выбор Python для автоматизации задач или JavaScript для создания сайтов. · (стр. 127)

### Обход типовых синтаксических ошибок · Спросите у Claude о самых частых ошибках новичков в выбранном языке и способах их избежать · Пример: промпт «What are the most common syntax errors beginners make in [language], and how can I avoid them?». · (стр. 130)

### Пошаговое планирование реального проекта · Прежде чем писать код, попросите Claude помочь спланировать шаги приложения и объяснить изучаемые концепции · Пример: промпт «Claude, I want to create a simple password strength checker in Python. Help me plan what it should do, and explain the programming concepts I’ll learn.» · (стр. 132)

### Использование безопасных методов для продакшна · Учитывайте ограничения учебного кода и применяйте защищенные модули для реальных задач · Пример: использование модуля `getpass` вместо обычного `input()` для скрытия паролей в терминале. · (стр. 135)

### Освоение инструментов среды разработки (IDE) · Запросите у Claude подсказки по изучению функций вашей IDE · Пример: промпт «What IDE features should I learn first in [your chosen IDE], and how do they help with [your programming language]?». · (стр. 138)

### Поиск и исправление ошибок («Резиновая уточка» и отладка) · Объясняйте код Claude строка за строкой или используйте системные запросы для локализации сбоев · Пример: промпт «Claude, my program crashes somewhere. Help me add print statements to figure out where the problem occurs...». · (стр. 140)

### Перевод сообщений об ошибках · Превращайте непонятные системные сбои в понятные объяснения с помощью ИИ · Пример: промпт «Claude, I’m getting this error: [paste error]. What does it mean in plain English, and what are the most common causes?». · (стр. 140)

### Проверка и улучшение кода (Code Review) · Используйте Claude в качестве рецензента для проверки функциональности, читаемости и безопасности · Пример: промпт «Claude, review this code for any obvious issues or improvements. Explain why each suggestion would make the code better.» или проверка на уязвимости для продакшна. · (стр. 142)

### Подготовка кода к реальному использованию · Всегда уточняйте у Claude разницу между учебным и промышленным кодом · Пример: промпт «What would I need to change in this educational code to make it suitable for real-world use?». · (стр. 148)

### Системный брейншторминг (Мозговой штурм) · Генерируйте идеи без предварительной фильтрации, используя структурированные методы (метод «Да, и...» или принудительные связи) · Пример: промпт «Generate 10 ideas for [problem], ranging from conventional to completely unconventional. Don’t filter for feasibility yet.» · (стр. 155)

### Дизайн-мышление для решения задач · Проходите через этапы эмпатии, переосмысления проблем («How might we...»), генерации и прототипирования с помощью ИИ · Пример: промпт «Help me reframe this problem statement: [vague problem]. Create 3 ‘How might we...’ questions that are specific, actionable, and human-centered.» · (стр. 158)

### Обратное проектирование (Backward Design) · Работайте от конечной цели в обратном направлении, разбивая большие мечты на ежедневные действия · Пример: промпт «Help me work backward from this goal: [big goal]. Break it into yearly, monthly, weekly, and daily actions...». · (стр. 162)

### Инновации в условиях ресурсных ограничений · Превращайте лимиты (бюджет, время) в творческие преимущества с помощью целевых промптов · Пример: промпт «I want to achieve [goal] but have these constraints: [list limitations]. Help me turn each constraint into a creative advantage...». · (стр. 164)
