### Планирование · Разделение сложных задач на подзадачи · Для решения сложных задач, требующих нескольких действий, агентам нужно выполнять их в разумном порядке и управлять зависимостями между ними (оркестрация) · (стр. 10).

### Ошибки · Обработка ошибок внешних сервисов · Реализуйте механизмы резервного копирования (fallback) или информативные сообщения об ошибках для пользователя при недоступности внешних API · (стр. 5).

### Безопасность · Защита при работе с API · Используйте HTTPS для передачи данных, надежную аутентификацию и авторизацию, а также маскируйте или анонимизируйте чувствительные данные для соблюдения конфиденциальности · (стр. 5).

### Экономия лимита · Учет лимитов запросов (rate limits) · Настраивайте агента так, чтобы он уважал лимиты внешних API, во избежание сбоев в работе · (стр. 5).
