### 1. Стратегия выбора закрытых LLM для быстрого прототипирования · Используйте закрытые LLM (через API) на этапе разработки и проверки идей, чтобы сразу сфокусироваться на логике агента без настройки инфраструктуры. · Пример: Старт с OpenAI API (например, gpt-5-mini или gpt-5) для быстрой проверки гипотез. · (стр. 21)

### 2. Поддержание непрерывности разговора вручную (работа со stateless API) · Накапливайте всю историю общения в списке `messages` и передавайте её целиком с каждым новым вызовом API, так как LLM по своей природе не имеют памяти о прошлых запросах. · Пример: Добавление пользовательских (`user`) и ассистентских (`assistant`) сообщений в список `messages` перед повторным вызовом модели. · (стр. 27–28)

### 3. Применение Pydantic для структурированного вывода · Используйте модели Pydantic (наследуемые от `BaseModel`) для создания схемы данных, гарантирующей, что LLM вернет ответ в нужном формате (например, JSON) для последующей обработки программами. · Пример: Определение класса `ExtractedInfo` с полями `name`, `email` и передача его в параметр `response_format`. · (стр. 28–29)

### 4. Ограничение одновременных запросов с помощью Semaphore · При запуске асинхронных задач через `asyncio.gather` используйте `asyncio.Semaphore`, чтобы ограничить число параллельных API-вызовов и избежать превышения лимитов (rate limits). · Пример: Оборачивание вызова `acompletion` в контекстный менеджер `async with semaphore:` с лимитом в 10 одновременных запросов. · (стр. 30)

### 5. Автоматический повтор при временных сбоях (Retry) · Настраивайте параметры автоматического повтора запросов с экспоненциальной задержкой, чтобы обрабатывать сетевые ошибки и временные ограничения API. · Пример: Использование параметра `num_retries=3` в LiteLLM для автоматического перезапуска неудачных вызовов. · (стр. 30–31)

### 6. Безопасная пакетная обработка через `return_exceptions=True` · При массовой оценке задач (например, тестов) защищайте групповые асинхронные вызовы аргументом `return_exceptions=True`, чтобы один сбой не отменял выполнение остальных задач. · Пример: Передача `return_exceptions=True` в `asyncio.gather(*tasks)`. · (стр. 31)

### 7. Проектирование системных промптов для автономного поведения агента · Прописывайте в системном промпте правило действовать самостоятельно при ясности намерений пользователя, а не переспрашивать разрешение. · Пример: Инструкция в промпте: «Когда намерение пользователя понятно, выполняйте действия немедленно без подтверждения. Задавайте минимальные вопросы для уточнения только при двусмысленности». · (стр. 33, 53)

### 8. Унификация провайдеров через LiteLLM · Используйте библиотеку LiteLLM для вызова разных языковых моделей через единый интерфейс, что позволяет легко переключаться между провайдерами без переписывания кода. · Пример: Использование функции `completion(model="gpt-5-mini", ...)` вместо специфичных SDK. · (стр. 26–27)
