### Настройка MTU для Windows · Изменяйте размер MTU интерфейса TAP под настройки сервера с помощью команды netsh (требуются права администратора). · Пример: `netsh interface ipv4 set subinterface "1" mtu=1400` · (стр. 20)

### Анализ производительности через tcpdump · Перехватывайте трафик OpenVPN на сетевом интерфейсе (не на туннеле) для отладки размеров пакетов и фрагментации. · Пример: `tcpdump -nnl -i eth0 udp port 1194` · (стр. 104)

### Автоматическое обновление DNS в Linux · Используйте встроенные скрипты OpenVPN (`client.up` / `client.down`) с директивой `script-security 2`, чтобы автоматически обновлять `/etc/resolv.conf` при получении DNS от сервера. · Пример: добавление `script-security 2`, `up "/etc/openvpn/cookbook/client.up"` в клиентский конфиг · (стр. 107)

### Повышение привилегий в Windows · Учитывайте, что современные версии OpenVPN GUI (2.3+) автоматически запрашивают повышение привилегий (UAC) при запуске даже без флага «Запуск от администратора». · Пример: отключение совместимости «Run this program as an administrator», после чего GUI всё равно выдаёт запрос UAC · (стр. 108)

### Использование хранилища CryptoAPI в Windows · Повышайте безопасность, заменяя plaintext-файлы ключей и сертификатов на хранилище сертификатов Windows CryptoAPI через конвертацию в PKCS12 и директиву `cryptoapicert`. · Пример: `cryptoapicert "SUBJ:Client2"` или `cryptoapicert "THUMB:<fingerprint>"` · (стр. 109)

### Обновление DNS-кэша в Windows · Добавляйте специальную директиву в конфиг клиента для принудительного обновления DNS-кэша и регистрации IP-адреса VPN в таблицах Windows при установке соединения. · Пример: `register-dns` · (стр. 110)
