### Обязательная настройка учетных данных · Добавьте учетные данные сервисов (например, X или OpenAI) в файл `.env`, чтобы агенты могли выполнять внешние действия. · При использовании интеграции с X укажите параметры в файле `.env` (например, `X_USERNAME`, `X_PASSWORD`), хотя для демонстрации можно обойтись и без них · (стр. 175)

### Предупреждение об ошибках и остановке цепи · Настройте агентов так, чтобы при любых ошибках они возвращали конкретное ключевое слово (например, `FAILURE`), что позволяет контролировать выполнение последовательности (Sequence) в дереве поведений. · Если ассистент сталкивается с ошибкой при поиске на YouTube или создании поста, он возвращает строку `FAILURE` · (стр. 175)

### Ограничение частоты запросов во избежание блокировок · Будьте осторожны с автоматической отправкой сообщений в соцсети через агентов: генерация более нескольких постов в день может привести к блокировке аккаунта. · Запуск ABT для постинга в X более чем пару раз в день гарантированно заблокирует ваш аккаунт · (стр. 176)

### Обратная цепочка (Back Chaining) для построения деревьев · Используйте метод обратной цепочки для проектирования дерева поведений (ABT), двигаясь от желаемой конечной цели к начальным условиям. · Порядок шагов: 1. Определить целевое поведение; 2. Выделить необходимые действия; 3. Выявить условия; 4. Определить способ коммуникации; 5. Построить дерево рекурсивно от цели к началу · (стр. 179)

### Минимизация количества ассистентов · На первом этапе создания дерева поведений пишите общие инструкции и старайтесь задействовать как можно меньше отдельных ассистентов, объединяя задачи там, где это возможно. · При создании ABT для помощи разработчику ассистентов начните с минимального набора ролей, разделяя только задачи тестирования и верификации · (стр. 180)

### Развертывание платформы для разработки · Установите платформу Nexus локально в режиме разработчика с помощью editable-установки через pip, чтобы иметь возможность изменять исходный код и работать с локальными файлами. · Выполните команды `git clone ...`, `pip install -e Nexus` и настройте переменные окружения в файле `.env` · (стр. 187)

### Использование состояния сессии в Streamlit · При создании веб-интерфейсов на Streamlit применяйте `st.session_state` для хранения истории чата и конфигурации моделей, так как сам скрипт является stateless и перезапускается при каждом действии пользователя. · Проверка наличия истории сообщений: `if "messages" not in st.session_state: st.session_state["messages"] = []` · (стр. 190)

### Отладка Streamlit-приложений · Настройте конфигурацию отладчика в файле `.vscode/launch.json` с типом `debugpy` для запуска модуля `streamlit` в режиме отладки. · Используйте конфигурацию с модулем `streamlit` и аргументами `["run", "${file}"]` для отладки по клавише F5 · (стр. 191)

### Потоковая передача ответов (Streaming) · Улучшайте пользовательский опыт и скрывайте задержки моделей с помощью потоковой передачи токенов в реальном времени. · Установите параметр `stream=True` при вызове `client.chat.completions.create` и используйте `st.write_stream(stream)` · (стр. 193)

### Разработка профилей агентов через YAML · Создавайте новые профили и персоны агентов, размещая YAML-файлы с описанием роли и доступных действий в специальной директории. · Создание файла `fiona.yaml` с полями `name`, `persona` и `actions` в папке `nexus_profiles` · (стр. 171)

### Создание нативных и семантических функций через декоратор · Превращайте обычные функции Python в инструменты для агента с помощью специального декоратора, который автоматически генерирует спецификацию инструментов (tools) для LLM. · Использование декоратора `@agent_action` над функциями для кода (native) или функциями с промптами в docstring (semantic) · (стр. 174)

### Параллельный вызов функций (Parallel Tool Calling) · Реализуйте в движке агента поддержку параллельного выполнения нескольких инструментов, запрашиваемых языковой моделью. · Агент обрабатывает массив `tool_calls`, выполняет все функции и возвращает их результаты обратно в стек сообщений модели для финального ответа · (стр. 176)
