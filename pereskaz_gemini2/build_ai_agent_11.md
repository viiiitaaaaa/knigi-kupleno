### Шаблон последовательного воркфлоу (Sequential) · Передавайте входные данные (`user_input`) только первому агенту в цепочке, а последующим агентам передавайте только обновляемый контекст. · `result = await agent.run(user_input, context=context, verbose=verbose)` для первого агента и без `user_input` для остальных. · (стр. 279)

### Сброс состояния в Sequential-воркфлоу · Перед запуском каждого следующего агента в цепочке сбрасывайте `context.final_result = None` и `context.current_step = 0`, чтобы состояние предыдущего агента не влияло на следующий. · `context.final_result = None; context.current_step = 0` · (стр. 279)

### Шаблон параллельного воркфлоу (Parallel) · Запускайте агентов параллельно с помощью `asyncio.gather` на одном входе, а при слиянии результатов фильтруйте дубликаты пользовательских событий и объединяйте новые события по авторам (`event.author`). · `results = await asyncio.gather(*[agent.run(...) for agent in self.agents])` · (стр. 281)

### Шаблон воркфлоу с циклом (Loop) · Повторяйте цепочку агентов итеративно до выполнения функции условия остановки (`stop_condition`) или достижения максимального числа итераций (`max_iterations`). · `def quality_reached(result: AgentResult, iteration: int) -> bool:` · (стр. 283)

### Изоляция контекста в паттерне «Агент как инструмент» · Вызывайте дочернего агента-специалиста в новом изолированном контексте, передавая ему только строку запроса и возвращая главному агенту исключительно финальный результат (`result.output`), не засоряя общий контекст промежуточными шагами. · `result = await self.agent.run(request)` · (стр. 269)

### Паттерн передачи управления (Transfer) · Передавайте управление целиком другому агенту вместо того, чтобы вызывать его как инструмент; при этом агент-получатель полностью наследует контекст предыдущего разговора и продолжает диалог с пользователем. · `router = Agent(name="router", sub_agents=[code_expert, math_expert])` · (стр. 276)

### Валидация дерева агентов · Запрещайте дублирование имен агентов и регистрацию агента у нескольких родителей одновременно при настройке дерева (`_validate_and_set_sub_agents`), чтобы сохранить однозначную иерархическую структуру. · `raise ValueError(f"Duplicate sub-agent name: '{sub.name}'")` · (стр. 275)
