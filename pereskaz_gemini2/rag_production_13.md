### Рабочий процесс слепой верификации (Blind Verification Workflow) · Для борьбы с визуальными галлюцинациями (сикофантством модели перед наводящими вопросами) сначала передавать изображение VLM с нейтральным промптом («Опишите состояние»), а затем сравнивать этот эталон с вопросом пользователя с помощью текстовой LLM · Instead of passing the user’s leading question directly to the VLM, you first pass the image to the VLM with a neutral prompt... ### Оценка генерации с помощью VLM-как-судьи (VLM-as-a-Judge) · Использовать сильную модель-судью, которой передаются ответ пайплайна, эталонный ответ и исходные изображения для оценки точности визуального рассуждения по шкале от 1 до 5 · construct a test set of complex images and associated gold reference Q&A pairs... pass the actual response, the reference response, and the retrieved images to a strong judge model · (стр. 302).

### Тестирование на жестких негативах (Hard Negatives) · Поддерживать небольшой тестовый набор визуально похожих изображений с противоречивыми данными, чтобы штрафовать модель за поверхностное «смотрение» без «чтения» · maintain a small hard negative test set—examples where images are visually similar... to ensure the evaluation metric penalizes the model for looking without reading · (стр. 303).
