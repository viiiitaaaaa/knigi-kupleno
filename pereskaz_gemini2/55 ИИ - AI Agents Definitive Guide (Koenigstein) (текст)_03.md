### Принцип «Человек в контуре» (Human-in-the-Loop, HITL) · Прерывайте выполнение агента в критических точках для обеспечения безопасности, проверки и подтверждения действий. · Используйте режим HITL для проверки аргументов вызова инструментов, изменения состояния или подтверждения запросов перед их отправкой внешним системам. (стр. 200–202)

### Пауза перед побочными эффектами · Никогда не размещайте код с побочными эффектами (вызовы API, запись в БД) в том же узле, где вызывается прерывание (`interrupt`). · Всегда сначала приостанавливайте выполнение и выполняйте операции только после явного одобрения, чтобы избежать повторов при возобновлении. (стр. 204)

### Параллельная обработка прерываний · Собирайте несколько независимых пользовательских решений одновременно с помощью нескольких узлов, вызывающих `interrupt`, а затем возобновляйте граф общей картой ответов (`Command(resume=resume_map)`). · Полезно, когда разные аналитики или проверяющие должны валидировать разные части вывода агента параллельно. (стр. 204–205)

### Архитектура «Супервайзер» (Supervisor MAS) · Делите сложные задачи на подзадачи с помощью многоагентной системы, где специализированные рабочие агенты подчиняются единому агенту-супервайзеру. · Суперагент использует структурированный вывод для динамического определения того, какой рабочий должен действовать следующим или когда завершить работу (`FINISH`). (стр. 206–208)

### Использование готовых компонентов для рабочих агентов · Применяйте повторно используемые фабричные функции (например, `create_react_agent` и хелперы узлов) для быстрого создания специализированных агентов с четкими ролями и инструментами. · Назначайте агентам узкоспециализированные роли через промпты (например, веб-исследователь, скрапер, патентный эксперт) без дублирования шаблонного кода. (стр. 208–210)

### Роевая архитектура (Swarm Architecture) · Организуйте динамическое сотрудничество агентов по принципу равный-с-равным через инструменты передачи управления (`create_handoff_tool`). · Позволяет рабочим агентам (например, исследователю и писателю) свободно передавать контекст и возвращать управление друг другу по мере необходимости. (стр. 212–214)
