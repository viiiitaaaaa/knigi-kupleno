### Планирование · Тщательное планирование задач до их выполнения с помощью глубоких агентов (Deep Agents). · Использовать подход «Deep Agents: Planning Before Execution». · (стр. из текста)
### Проверка результата · Изоляция и проверка результатов инструментов для предотвращения выполнения инъекций промптов. · Запускать инструменты через минимальный интерпретатор Python (например, Monty) с предварительным сохранением контрольных точек (checkpoint) перед каждым вызовом. · (стр. из текста)
### Память · Организация топологии памяти агентов (эпизодическая, семантическая, процедурная долгосрочная память, а также краткосрочная память). · Разделять память на уровни (пространства имен, персистентность на уровне вызовов или потоков) с помощью гигиены памяти для поддержания ее актуальности. · (стр. из текста)
### Контекст · Использование кэширования префиксов (prefix caching) и KV-кэширования (включая paged KV caching) для оптимизации работы контекста и inference-бэкендов. · Применять префиксное кэширование и оптимизацию памяти для снижения издержек на длинные контексты. · (стр. из текста)
### Безопасность · Раннее тестирование угроз, защита от инъекций промптов (prompt injection) и изоляция среды с помощью Docker. · Применять изоляцию во время выполнения (Runtime Isolation with Docker), проверять валидность памяти перед персистентностью и использовать фреймворки раннего тестирования угроз (например, на основе OWASP ASI Top 10). · (стр. из текста)
### Экономия лимита · Валидация данных и контроль затрат на передачу данных (handoffs) с помощью библиотеки Pydantic. · Использовать Pydantic для проверки данных и политик, чтобы избегать лишних трат токенов и ресурсов GPU. · (стр. из текста)
