### Изучение категории через комбинацию · Объединяйте 2–3 простых слова, чтобы создать ассоциацию для абстрактного слова или категории (например, животное через свинью, рыбу и козу). · Пример: Немецкое слово *Tier* (животное) через набор конкретных образов. · (стр. 204–205)

### Добавление контекста и подсказок для похожих слов · Используйте личную заметку (например, имя реального человека) или короткое слово-подсказку из уже известного списка, чтобы различать похожие понятия. · Пример: Различение «племянницы» (*Nichte* — через имя Элиана) и «дочери» (*Tochter* — через слово *Mutter*). · (стр. 206)

### Создание карточек для мнемонических образов · Используйте SRS-карточки не только для слов, но и для отслеживания мнемонических ассоциаций (например, для родов существительных или спряжений), чтобы не путать образы. · Пример: Карточки для сортировки мнемонических картинок грамматических правил. · (стр. 208)

### Карточки на основе предложений (Sentence Play) · Собирайте информацию из предложений по частям: контекст (история), перевод слов (чанки), базовые формы и картинки, создавая иммерсивные карточки без родного языка. · Пример: Разбор предложения «He lives in New York City». · (стр. 210–212)

### Четыре типа карточек для новых слов и форм · Создавайте 2–4 карточки на слово/форму: 1) пропуск слова в предложении, 2) генерация фразы с этим словом, 3) пропуск в другом контексте для многозначности, 4) правописание (при необходимости). · Пример: Карточки для слова *in* или формы *lives*. · (стр. 213–218, 220–225)

### Карточки на порядок слов (Word Order) · Используйте карточки на позицию слова в предложении, чтобы на уровне интуиции усвоить структуру построения фраз. · Пример: Указание места для слова *He* в предложении «Lives in New York City». · (стр. 225–226)

### Устранение слишком явных подсказок · Если пример дает нежелательную подсказку (например, артикль *an* указывает на гласную), убирайте её из карточки, чтобы усложнить задачу мозгу. · Пример: Замена фразы с «an automatic rifle» на вариант без артикля-подсказки. · (стр. 229)

### Универсальная карточка-заглушка · При тупике с грамматикой или для повторения исправленной ошибки делайте простую базовую карточку с пропуском и картинкой, не усложняя процесс. · Пример: Превращение сложного грамматического случая в стандартный тест с пропуском. · (стр. 229–230)

### Использование толкового словаря с переводчиком · Изучайте абстрактные слова через короткие определения из моноязычного словаря, открывая его через онлайн-переводчик для быстрого понимания. · Пример: Поиск короткого определения для слова *honest* с переводимыми подсказками при наведении мыши. · (стр. 231–232)
