### Шаблон промпта для маршрутизации (LLM-Based Routing) · Использовать системный промпт для классификации запроса пользователя на категории с выдачей строго одного слова для последующего ветвления. · Пример: `analysis of the user's request and determine which specialist handler should process it. - If related to booking, output 'booker'. - For general info, output 'info'. - If unclear, output 'unclear'. ONLY output one word: 'booker', 'info', or 'unclear'.` · (стр. 40)

### Шаблон паттерна цепочки промптов (Prompt Chaining) · Разбивать сложные задачи на последовательность простых шагов, где вывод каждого предыдущего шага служит входом для следующего (модульная стратегия «разделяй и властвуй»). · Пример: Шаг 1 (извлечение спецификаций) -> Шаг 2 (трансформация в JSON объект с ключами cpu, memory, storage). · (стр. 30)

### Контекстная инженерия (Context Engineering) · Проектировать богатую информационную среду перед генерацией токенов, объединяя системный промпт, внешние документы, вызовы инструментов (API) и неявные данные (история, профиль). · Пример: Интеграция календаря пользователя (вывод инструмента), рабочей истории (неявные данные) и заметок прошлых встреч (извлеченные документы) перед генерацией ответа. · (стр. 31–32)

### Использование внешнего калькулятора (External Tool Delegation) · Делегировать точные математические вычисления внешним инструментам, так как LLM склонны к ошибкам в арифметике. · Пример: LLM идентифицирует нужную операцию, передает нормализованные числа калькулятору и внедряет точный результат. · (стр. 27)

### Параллельная обработка независимых задач (Parallelization / Map Chain) · Запускать независимые подзадачи одновременно (через асинхронность или параллельные ветки в графе), чтобы сократить общее время выполнения перед финальным объединением. · Пример: Одновременное создание краткой выжимки (summary), генерация вопросов (questions) и извлечение ключевых терминов (key_terms) по одной теме с последующим синтезом. · (стр. 55)

### Обработка пропущенных или некорректных данных (Conditional Prompt Chaining) · Проверять результаты извлечения по структуре и при ошибках запускать условный повторный промпт с уточнением отсутствующей информации. · Пример: Проверка наличия всех полей в инвойсе; если поле повреждено или пропущено — отправка нового точечного запроса с контекстом сбоя. · (стр. 27)

### Использование метода .strip() при обработке решений роутера (Error Prevention) · Всегда очищать текстовый вывод языковой модели-классификатора от пробелов и переносов строк при сопоставлении веток (branching), чтобы избежать сбоев условий. · Пример: `(lambda x: x['decision'].strip() == 'booker', branches["booker"])`. · (стр. 41)
