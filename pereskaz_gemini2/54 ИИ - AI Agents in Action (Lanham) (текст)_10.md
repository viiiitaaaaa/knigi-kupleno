### Сравнение прогонов (Visualize Runs) · Сравнивайте агрегированные метрики и результаты различных вариантов промптов через Batch Run History, чтобы находить оптимальные конфигурации профилей ИИ. · Откройте расширение prompt flow, перейдите в раздел Batch Run History, выберите нужные прогоны, щелкните правой кнопкой мыши и выберите Visualize Runs. · (стр. 264)

### Использование пакетного режима для симуляции циклов · Применяйте пакетную обработку в prompt flow (через кнопку Batch / иконку колбы) для многократной генерации ответов на одинаковый ввод, так как ацикличные граф-схемы (DAG) не поддерживают циклы напрямую. · Выберите локальный файл данных (например, statements.jsonl с одинаковыми записями) для генерации множества вариантов плана или решения. · (стр. 286)

### Магическая фраза для рассуждений · Добавляйте в системный промпт фразу «Let's think step by step» (Думайте шаг за шагом), чтобы принудительно запустить у ИИ механизм пошагового логического рассуждения без использования сложных примеров (few-shot). · Укажите в системном промпте: «You are an expert... Let's think step by step. Please finalize your answer in a single statement.» · (стр. 282)

### Пошаговое деление задач (Prompt Chaining) · Разбивайте сложный процесс решения задачи на цепочку последовательных промптов (декомпозиция шагов $\rightarrow$ вычисление шагов $\rightarrow$ итоговое решение), чтобы принудительно заставить LLM строить логические цепочки. · Передавайте вывод предыдущего блока LLM в качестве входных данных для следующего блока в файле `flow.dag.yaml`. · (стр. 258)

### Самосогласованность (Self-Consistency) · Генерируйте несколько различных планов или решений для одной задачи (например, с более высокой температурой), а затем оценивайте их и выбирайте наиболее часто встречающийся (консистентный) ответ. · Создайте несколько вариантов ответа на проблему и примените скрипт оценки сходства (например, через косинусное расстояние в `consistency.py`), чтобы определить лучший результат. · (стр. 262)

### Ограничение лишнего вывода в промптах · Всегда явно прописывайте в системном сообщении инструкции возвращать только запрошенный результат и ничего лишнего (например, только итоговую оценку или только сгенерированное предложение), чтобы избежать ненужных объяснений от ИИ. · Добавьте в промпт правило: «Please only return the sentence requested by the user» или «Return a score... and not the explanation». · (стр. 250)
