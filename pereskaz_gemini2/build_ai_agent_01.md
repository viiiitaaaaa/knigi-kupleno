### Эффективная работа с контекстом (Context Engineering) · Управлять качеством агента через управление входным потоком (контекстом) в цикле LLM-вызовов вместо слепой погони за большими контекстными окнами. · «The first was context engineering. It grew from the realizations that an agent is really a loop of repeated LLM calls and that now that models are capable enough, an agent’s quality turns on how well you manage the input that flows through that loop... Bigger context isn’t always better» (стр. 10, 15).
