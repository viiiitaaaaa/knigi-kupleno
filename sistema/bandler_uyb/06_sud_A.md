Повторяющиеся слабости скилла love-scripts:
1. Уточняющий вопрос не держит рамку «ОДИН и по сути»: либо разрастается в набор (A6), либо не тот вопрос, что нужен по критерию.
2. Не различает канал: приём на воображение даёт как для чата, без оговорки «закрой глаза там, где можно» и без «одна ручка» (A3).
3. В тяжёлом случае всё равно подсовывает «заземление/маленький приём» и телефоны горячих линий, а надо без техник и без номеров (A4).
4. Выдаёт готовый набор из 3 шаблонов вместо вариантов «если было так / если иначе» по ответу на вопрос (A6).
5. Не добавляет обязательные пометки к смежным темам (например «уверенность ≠ компетентность» для денег, A1); общее правило «не из книги» ставит, но шаги книги подменяет общими.
