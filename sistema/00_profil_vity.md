# Профиль Виты для подбора ситуаций (ЧЕРНОВИК 19.10.2026 — по тому, что уже известно из памяти; Вита поправит)

Правило: Вита не пересказывает жизнь. Я заполняю по памяти и показываю на подтверждение; раз в неделю — одно нажатие «какие из ситуаций случились?».

1. Роли сейчас: ИП (своё дело), продавец/поставщик в интернет-магазинах (идеи: одежда США, дропшиппинг, 1688), соискатель работы (резюме, питч, вакансии), ученица (IT/Python, английский), исполнитель-фрилансер у «партнёров» (лидогенерация), клиентка по юр-делам, женщина в знакомствах.
2. Цели на 90 дней: заработать на своём деле; договориться об оплате до начала работы; найти работу/клиентов; выучить Python/английский; наладить здоровье и вес.
3. Повторяющиеся процессы: поставщики и посредники (1688, CJ), переписка с китайскими поставщиками, переговоры с заказчиками (Паша, подруга-юрист), знакомства/переписка с мужчинами, обучение по книгам, бот похудения.
4. Ближайшие переходы: первый платный пилот; запуск рекламы; новые страны/каналы; собеседования; встречи/свидания.
5. Границы: не манипулировать; здоровье (ОКР/питание) — осторожно, без советов вместо врача; деньги — только после письменных условий; ключи/пароли никуда.

6. Каналы общения (её слово 19.10.2026): НЕ только мессенджеры — живые встречи, телефон/голос и мессенджеры. Приёмы книг, описанные для живого разговора, применяются как написаны; отдельно помечать канал только там, где приём зависит от голоса/паузы (зеркало, тишина).

7. Эмоции и опасные приёмы (её слово 19.10.2026): рассматривать ВСЕ эмоции (свои и чужие, в т.ч. тяжёлые) и ВСЕ приёмы, в т.ч. манипулятивные, — в режиме ЗАЩИТЫ: признак → как это работает → как защититься/ответить. Не как готовые скрипты, чтобы применять к другим. Медицинские/кризисные вещи — без диагнозов, при необходимости специалист.

8. Люди разных стран (её слово 19.10.2026): работает и будет работать с русскими, американцами, китайцами и другими — НЕ подгонять советы под одну нацию. Культура собеседника — переменная: узнавать по его ответам и контексту, не делать выводов «все китайцы/американцы/русские такие».

9. Пробелы в книгах (её слово 19.10.2026): где в книге ничего нет — не мучиться, написать общими словами (общий принцип, помечено «не из книги»), без долгих раздумий. Ей понравилась мысль Klaff: «если твой ход вызвал у человека защиту — ты перегнул, притормози».

10. Поправки Виты (19.10.2026): у неё ЕСТЬ представление о рынке для сравнения цен; есть юрист, большие договоры оформить может (не считать это пробелом и не упрощать «под маленький проект»); кто решает о деньгах — она оценивает сама по ситуации.

11. Поправки Виты (19.10.2026): у неё ЕСТЬ реальные кейсы (напр. снизила клиенту себестоимость и подняла прибыль на 10–15%); у неё ЕСТЬ роль — руководитель своего частного проекта (консультационные услуги); рекомендации ей не нужны (не просить); договорённости будут по ходу (например с инвестором). Не писать «у неё нет кейсов/роли». Старые строки скиллов про «нет кейсов» относятся к конкретным случаям (Паша, подруга-юрист, лидогенерация), перепроверить и уточнить у неё, какие кейсы можно показывать (данные клиентов — только с их согласия).

Статус: черновик, не подтверждён. Подтвердить одним ответом «да / поправь».
