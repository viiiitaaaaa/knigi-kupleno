На пальцах:

Простая проверка: если шаги всегда одинаковые, это скрипт. По описанию твоих новостей (собрать, разобрать, обновить панель) шаги одинаковые.

Нужно ли делать агентом? Книга задаёт два вопроса: нужна ли тут модель вообще? А если нужна, хватит ли обычного сценария? Для повторяемых вещей наш скилл говорит так же: держать скриптом, ИИ только там, где нужна гибкость. Агент дороже и ненадёжнее.

Решение за тобой. Мой совет сейчас: не переделывать.

Капля Python:
```
while True:        # «повторяй»
    шаг = модель_выбери_шаг()   # агент: шаг выбирает модель
```
`while True` значит «повторяй без конца, пока не скажут стоп». У скрипта вместо этого просто список шагов сверху вниз.

Запомни: если шаги всегда одинаковые, агент не нужен.

## B5

Не «вроде работает», а набор проверок из твоих прошлых жалоб. Это и есть тест.

Идея: каждая жалоба превращается в случай «что подали → что должно получиться».

Пример на 4 случая (замени на свои настоящие):
| Что подали | Правильный итог |
|---|---|
| Лента не прочиталась | Написано «нового нет, лента не прочиталась», а не «нового нет» |
| Поставщик не отвечает | «Данных нет», цена не выдумана |
| Товаров 250 | В магазине изменилось 250 из 250, не 248 |
| Нарочно сломанный случай (канарейка, то есть ловушка) | Проверка краснеет, иначе сама проверка неисправна |

Как прогонять: скрипт считает, сколько случаев прошло. Две строчки Python:
```
if найдено == ожидалось:           # «если сошлось с эталоном»
    прошло += 1
print(f"{прошло} из {всего}")      # «покажи: прошло N из M»
```
`if` значит «если», `print` значит «напечатай».

Правила:
- Что можно проверить скриптом, проверяет скрипт, не модель.
- Правило «прошёл / не прошёл», а не оценки 1–5.
- После любой правки скилла или бота прогон заново. Стало хуже — не оставляем.
- Агент сам себя не проверяет.

Сколько случаев нужно и какой порог «хорошо» — не знаю, цифру не выдумываю. В книге ориентир 20–50 случаев на правку, это опыт авторов, не твой расчёт.

Данные дел — 🟡, в облачного «судью» не отправляем.

Метка: идея с тестом из книги (глава про оценку); жалобы как случаи, канарейка — из нашего скилла.
