## Повторяющиеся слабости
1. Теряются «мелкие» обязательные пункты скилла: ориентиры и чек-листы (маржа ≥ 65%, правило CAC < валовой прибыли, порог ~100 заказов, зачёркнутая цена) пропущены в B3, B6.
2. Не везде названы цвета данных 🟢/🟡/🔴 (B4, B5 — список клиенток, фото покупательниц).
3. Термины расшифрованы выборочно (маржа, потолок цены, налог с продаж, метрики тщеславия остались без объяснения).
4. Нет конкретных «честных путей» вместо запрещённого (B4: письмо после доставки, обмен размера, приложение отзывов) — ответ запрещает и предлагает только скидку/доставку.
5. Цифры книги даны без точного значения или без метки (75% в B4); а контрольные шаги «после её „да“ и копии» (B5) не проговорены.
6. Запретов ответы не нарушают: честное «не знаю / не из книги», токен не взят, налог не назван — сильная сторона.
