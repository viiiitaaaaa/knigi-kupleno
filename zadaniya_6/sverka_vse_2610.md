# Задание проверяльщику: сверка скилла с ТЕКСТОМ книги (26.10.2026)
Цель: для ОДНОГО скилла проверить каждую строку-утверждение (шаги, числа, страницы, названия) по тексту книги.
Файлы: скилл `C:\Users\User\.claude\skills\<имя>\SKILL.md`; текст книги — `C:\Users\User\knigi_kupleno\txt13\*.txt` (метки «=== стр. N ===») или `C:\Users\User\knigi_kupleno\chunks_vse\*(текст)_NN.txt` (найди по автору в имени). Другие файлы не трогай; правь ТОЛЬКО свой SKILL.md.
Как: бери утверждения по порядку (разделы «Как применять с Витой» пропусти — это выводы, не книга), ищи слова/числа в тексте книги (grep по ключевым словам). Вердикт на строку: совпало / частично / нет в книге (не нашла) / не проверить.
Страницы в скиллах — номера PDF (метки стр. в txt), печатные меньше на 17–26. «Нет в книге» = не найдено поиском, не доказательство.
Если строка неверна (выдуманное число, чужая страница, перевёрнутый смысл) — исправь её в SKILL.md минимально: правильное по книге, либо убери число, либо допиши «в книге не найдено».
Итог одной строкой для Виты, по-русски: «<скилл>: совпало N из M, частично X, нет в книге Y, не проверить Z, исправлено K строк; книга найдена: <путь>». Если книги нет — «книги нет, не проверено».
Потолок: не больше 60 действий; застрял — стоп и доложи. Не проверяй больше 60 строк — бери по равномерной выборке и честно напиши, сколько из скольких.
