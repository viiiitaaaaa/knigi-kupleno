# Задание: конспект купленной книги

## Каким должен быть итог («готово»)
Для каждой твоей книги — один файл `C:\Users\User\.claude\skills\knowledge-library\references\knigi\<slug>.md`
(slug — латиницей, коротко, например `kotler_marketing_management_1.md`), UTF-8, на русском. В нём:

1. **Шапка**: название, автор(ы), год, язык оригинала, объём, исходный файл в `G:\Мой диск\куплено\`.
2. **О книге в 3–5 строк** — о чём и для кого, чем полезна именно нам.
3. **Конспект по главам** — каждая глава/часть отдельным подзаголовком: главные идеи, модели, формулы,
   чек-листы, цифры и примеры — простыми словами, термины расшифровывать (пользователь — новичок).
   Не пересказ «вода», а то, что можно применить. Объём — сколько нужно для полноты: для учебника
   это 1–3 тыс. слов на главу не страшно; для тонкой книги — меньше.
4. **«Что применяем у нас»** — конкретные приёмы под наши дела, каждый с пометкой, в какой скилл его
   разнести: `→ dropship-lessons`, `→ site-design`, `→ b2b-sbor`, `→ claude-code-priemy`, `→ tg-news`,
   `→ shopify-admin`, `→ trend-radar`, `→ sourcing-1688`, `→ kursy-konspekty`, `→ knowledge-library` и т.п.
   Формат приёма: «что сделать — зачем — когда (в какой момент работы)».
5. **Чего НЕ брать** — устаревшее или не подходящее нам (с причиной).

Книга, разбитая на 2 агентов (part 1/2): пиши файл `_1.md` / `_2.md` только своих глав.
