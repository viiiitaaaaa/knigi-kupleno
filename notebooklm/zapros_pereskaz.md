# Запросы к NotebookLM (вставлять одной строкой)

## 1. Учебный конспект (первый запрос по книге)
Сделай подробный учебный конспект этой книги на русском (английские термины — в скобках). Разделы: 0. Полный список глав книги (номер, название по-английски — перевод); 1. О чём книга в 3 предложениях; 2. Главные идеи по главам (по каждой главе 3–5 пунктов); 3. Схема связей между главными идеями в формате Mermaid (graph TD) в блоке кода; 4. Пошаговый чек-лист практических действий; 5. Типичные ошибки и как их избежать; 6. 20 карточек «вопрос — ответ» для повторения; 7. 5 практических заданий на применение (для интернет-магазина одежды, B2B-лидогенерации и сборщиков данных на Claude/Python). Опирайся только на книгу.

## 2. Подробный пересказ (по 2–3 главы за запрос; N, M — номера глав)
Сделай подробный пересказ глав N–M книги. Формат для каждой главы: заголовок «Chapter N. <англ.> / Глава N. <рус.>»; «Главная мысль автора»; «Ключевые формулировки автора» — 2–4 дословные цитаты на английском в кавычках и перевод; по каждому разделу главы: заголовок «англ. / рус.», «Мысли автора по порядку», все цифры, примеры и истории (кто → что сделал → итог), что делает пример кода (без самого кода; для книг с кодом), номера рисунков и таблиц; таблицы — таблицами; в конце «Summary / Резюме главы N». Ничего не сокращай и не добавляй от себя — только то, что есть в книге.

## Перед запросом
Проверить по chunks_vse, что глава/приложение есть в нашем файле книги: NotebookLM сочиняет отсутствующие разделы целиком (16.10: приложение F у Гулли).
