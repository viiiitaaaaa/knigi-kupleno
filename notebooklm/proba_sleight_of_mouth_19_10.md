# Проба: сколько теряется из книги (Sleight of Mouth, 19.10.2026)

Сравнили 3 слоя: (1) новый конспект NotebookLM (37 КБ), (2) моя заметка v_skilly 18.10, (3) то, что УЖЕ лежит в скилле dogovorennosti с 14.10 (раздел «Dilts Sleight of Mouth», 35 пунктов, `references\iz_knig_novye13.md`, строки 387–432).

## Итог
- Гипотеза «теряем до 90%» для ЭТОЙ книги НЕ подтвердилась. Старый способ (полный текст + несколько проходов) дал все 14 приёмов: формула из книги, пример книги, готовые ответы, граница «когда нельзя», страницы книги. Это уже почти карточки.
- NotebookLM-конспект слабее старого: назвал ~9 из 14 приёмов, формул нет. Моя v_skilly по нему (18.10) занижала — «не все 14 названы» неверно для скилла: все 14 там есть.
- Реальные дыры старого способа (их и надо закрывать, а не перечитывать):
  1. Нет проверки (тестовых вопросов): сработает ли скилл на «дорого», «потом рассчитаемся», «процент с заявок». 
  2. Всё примерено на один случай (Паша/подруга-юрист); для магазина (покупатель «дорого»), лидогенерации, обучения — только 1–2 строки.
  3. Нет тренажёра для Виты: 14 приёмов = много; нужны 3–4 главных и ежедневная практика (30-минутное занятие).
  4. Нет статуса «проверено в жизни» у каждого приёма.

## Что делать вместо перечитывания
1. Для самых нужных книг (переговоры о цене: Voss, Weiss, Sleight of Mouth, Challenger, SPIN) — завести 10–15 тест-вопросов на скилл (реплика клиента → ожидаемое поведение).
2. Выбрать 3–4 приёма в учебную неделю Виты (по формуле Perplexity), остальные — справочник.
3. Каждый приём получает статус: candidate → tested → approved после реальной попытки.
4. NotebookLM-конспекты — запасной слой для сверки и для книг, где старого разбора нет (ОКР, тело, часть НЛП).
