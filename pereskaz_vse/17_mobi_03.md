## Content Creation and Blogging (Создание контента и блоги)

- **Основные идеи**  
  - Пишите собственный сильный контент, если готовые статьи не соответствуют вашему уровню (стр. —).  
  - Нужно достаточно контента для маркетинга сайта: размещать его на своём сайте, вести гостевые посты, публиковать на статья‑сайтах, отвечать на вопросы в форумах (стр. —).  
  - Не размещайте одну и ту же запись многократно – поисковые системы замечают дублирование (стр. —).  
  - Не создавайте «спамные» статьи: плохо написанные, с переизбытком ключевых слов, не приносящие ценность читателю (стр. —).  

- **Рекомендации**  
  - Делайте 1–2 новых статьи в неделю, ориентированные на целевые поисковые запросы (стр. —).  
  - Используйте материал для внутренней перелинковки (стр. —).

## Internal Linking and Anchor Text (Внутренняя перелинковка и якорный текст)

- **Важность внутренней перелинковки** – если статья упоминает тему/услугу, уже существующую на сайте, ставьте ссылку на эту страницу (стр. —).  

- **Anchor text (якорный текст)** – видимый текст ссылки, который поисковые системы используют для определения тематики целевого документа (стр. —).  

- **HTML‑код для вставки якорного текста**  

  ```html
  <a href="http://www.sovomedia.com">Seattle SEO Agency</a>
  ```
  *«Seattle SEO Agency»* будет отображаться в тексте как ссылка, указывающая на `http://www.sovomedia.com`. Это сообщает поисковикам о теме статьи и одновременно улучшает профиль ссылок (стр. —).

## Triberr (Триббэр)

- **Что это** – онлайн‑сообщество блогеров, использующее соцсети (Facebook, Twitter, Google Plus и др.) для взаимного распространения контента (стр. —).  

- **Как работает**  
  1. Пользователи группируются в «племена» (tribes) по нишам.  
  2. При публикации поста участник племени автоматически твитит его от имени всех остальных (стр. —).  

- **Требования к вступлению**  
  - Нужно быть принятым в уже существующее племя (поиск племени → запрос вступления или получение приглашения от лидера).  
  - Чем больше у вас подписчиков в Twitter, тем выше шанс попасть в топ‑племена с большой аудиторией (стр. —).

## Chapter 12: The Step‑by‑Step SEO Method (Глава 12: Поэтапный метод SEO)

### Общий совет

> **Главная причина неудач** – преждевременное прекращение работы. Нужно сохранять терпение; результаты могут появиться спустя 2–3 мес., иногда сразу (стр. —).  

### План действий (Step‑by‑Step)

#### Step 1 – Keyword Selection (Шаг 1 – Выбор ключевых слов)

1. Выберите **5‑10** поисковых запросов.  
2. Дальность сложности – низкая‑средняя (по инструментам).  
3. Объём поиска – минимум **1 000** запросов/мес. (если возможно).  
4. Запишите приоритет в **Excel** (стр. —).  

#### Step 2 – Onsite Optimization (Шаг 2 – Оптимизация сайта)

- **Обновить теги** с целевыми словами:  

  - `<H1>` заголовок  
  - `<title>`  
  - `meta description`  
  - Основной контент (включить ключевые слова в первые 25 и последние 25 слов, выделить их **жирным** один раз)  

- **Удалить** `<meta name="keywords">`.  

- **Создать подстраницы** для важных ключевых слов (пример: `www.roofer.com/seattleroofing.html`) (стр. —).  

- **Проверить ошибки** с помощью рекомендованных инструментов и Google Webmaster Tools; исправлять до полного удовлетворения (стр. —).  

#### Step 3 – Link‑Building Activities (Шаг 3 – Мероприятия по построению ссылок)

- **Создание карт‑цитат** – минимум **10** локальных каталогов в месяц.  
- **Статьи** – оформить **5‑10** аккаунтов на статейных каталогах, публиковать **5** статей/мес. с анкор‑ссылками.  
- **Пресс‑релизы** – один релиз в месяц (PRLog / PRWeb) с встроенными ссылками.  
- **Конкурентный линк‑билдинг** –  

  1. Поиск топ‑сайтов по целевому запросу.  
  2. С помощью выбранных инструментов получить их обратные ссылки.  
  3. Выбрать **10** потенциальных партнёров, написать им e‑mail с просьбой разместить ссылку.  

- **Социальные закладки** – минимум **10** новых записей в месяц на сайтах из списка.  
- **Соц‑медиа** – посты в Facebook (4 поста), рост подписчиков; активность в Twitter (2 твита) и Google Plus (2 поста).  
- **Каталоги** – заполнить **10** профилей в высоко‑ранжируемых каталогах.  
- **Блог и форумы** –  

  - 1 статья в блоге в неделю.  
  - 1 гостевой пост в месяц через Blogger Link Up.  
  - Увеличить охват через Triberr.  
  - Комментарии в форумах через BoardReader (как минимум раз в месяц).  

- **Отчётность** –  

  - Установить Google Analytics и отслеживать весь сайт.  
  - Отслеживать позиции ключевых слов (любым из перечисленных инструментов).  
  - Регулярно (каждые 2 недели) проверять Majestic SEO и Google Analytics для контроля роста ссылок и трафика.

| **Editorial Link** | Link earned editorially, valued over bought links. | Редакционная ссылка – полученная естественно, более ценная. |
| **Entry Page** | Page where a visitor enters the site. | Входная страница – первая открытая пользователем страница. |
| **Ethical SEO** | Techniques considered legitimate by search engines. | Этичный SEO – приемы, не нарушающие правила поисковиков. |
| **Everflux** | Continuous updating of search indexes (formerly Google Dance). | Everflux – постоянное обновление индекса (ранее «Google Dance»). |
| **External Link** | Link pointing to another domain. | Внешняя ссылка – ведёт на другой домен. |
| **Feed** | RSS/XML stream for content updates. | Фид – RSS/XML лента для обновлений контента. |
| **Flash** | Vector‑graphics animation; hard for search engines to index. | Flash – анимация в формате Flash, трудна для индексации. |
| **Forward Links** | See Outbound Links. | Внешние ссылки – см. Outbound Links. |
| **Fresh Content** | New, dynamic content that keeps users engaged. | Свежий контент – новый, динамичный материал. |
| **FTP (File Transfer Protocol)** | Protocol for transferring data between computers. | FTP – протокол передачи файлов. |
| **Google Advertising Professional (GAP)** | Program certifying AdWords proficiency. | GAP – сертификат профессионала Google Ads. |
| **Google** | Leading search engine; pioneered PageRank. | Google – ведущая поисковая система. |
| **Google Bot** | Google’s web‑spider crawler. | Google Bot – паук Google. |
| **Google Bombing** | Boosting a page’s rank for a specific query via many links. | Google Bombing – искусственное повышение позиции страницы. |
| **Google Bowling** | Knocking a competitor out of results with low‑trust links. | Google Bowling – вытеснение конкурента низкокачественными ссылками. |
| **Google Dance** | Former monthly index update (now continuous – Everflux). | Google Dance – прежний ежемесячный “танец” индекса. |
| **Google Keyword Tool** | Keyword research tool estimating traffic and competition. | Google Keyword Tool – инструмент исследования ключевых слов. |
| **Google Sitemaps** | Program to help Google index site content. | Google Sitemaps – карта сайта для облегчения индексации. |
| **Headings** | Elements `<H1>`‑`<H6>` structuring a document; only one `<H1>` per page. | Заголовки – элементы `<H1>`‑`<H6>` для структуры; один `<H1>` на страницу. |
| **Headline** | Title of an article or story. | Заголовок – название статьи/рассказа. |
| **Hidden Text** | SEO technique showing text to bots but not users; risky. | Скрытый текст – показывается только поисковикам, часто считается спамом. |
| **HITS** | Link‑based algorithm ranking relevance via citations. | HITS – алгоритм, оценивающий релевантность через ссылки. |
| **Home Page** | Main page of a website; key for branding and navigation. | Главная страница – основной вход в сайт, важна для бренда. |
| **HTML (Hypertext Markup Language)** | Language used to create web pages. | HTML – язык разметки веб‑страниц. |
| **HTTP (Hypertext Transfer Protocol)** | Primary protocol for communication between servers and browsers. | HTTP – основной протокол для обмена между сервером и браузером. |
