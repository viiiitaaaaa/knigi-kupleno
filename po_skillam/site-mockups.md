# Приёмы из книг для скилла site-mockups (3)

[grewal_marketing_2] 23. **Быстрые остроумные ответы на инфоповоды** (Vegemite vs Marmite) возможны, только когда есть чёткая «платформа бренда» в одну фразу — сформулировать её до запуска соцсетей. `→ site-mockups`, `→ dropship-lessons`

[kotler_entrepreneurial_marketing] 26. **Не перевкладываться в «творчество».** Что сделать: на генерацию креативов и макетов (ComfyUI, сцены) ставить
    дедлайн и бюджет; считать долю реализованных идей (R/I). Когда отдача падает, остановиться. Зачем: 4 зоны вложений
    из гл. 8, после оптимума — выгорание и спад. Когда: работа с site-mockups, room-scenes, креативами.
    → `site-mockups`, `dropship-lessons`

[kotler_marketing_management_1] 11. **Мишень бренда (Bull's-Eye) на одну страницу:** мантра (3–5 слов, внутренняя) → 2–3 точки отличия + точки паритета → «причины поверить» → личность (из 5: искренность / азарт / компетентность / изысканность / суровость) и визуальные элементы. Зачем — фильтр для всех решений: какие товары брать, какой тон в рекламе. Когда — при создании бренда магазина и дизайн-системы. `→ site-design`, `→ site-mockups`
