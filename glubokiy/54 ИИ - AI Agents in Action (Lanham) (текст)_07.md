# Конспект Части 7 книги «54 ИИ - AI Agents in Action» (Главы 6.3–7.6)

Конспект подготовлен для ИИ-помощника Claude, работающего с предпринимателем-одиночкой (учёт данных, скрипты, агенты, обучение). Все термины и правила взяты строго из текста.

## 6.3.5 Required X setup & Agentic Behavior Trees (стр. 175–176)
- Главная мысль — Демонстрация дерева поведения агентов (ABT), которое выполняет поиск на YouTube, пишет пост для Twitter/X и публикует его.
- Шаги процесса:
  1. Добавить учетные данные X (Twitter) в файл `.env` (стр. 175).
  2. Создать три агента в Playground: `YouTube Researcher v2`, `Twitter Post Writer`, `Social Media Assistant` (стр. 175–176).
  3. Запустить скрипт `agentic_btree_video_poster_v1.py` для поиска, суммаризации и создания файла публикации `youtube_twitter_post.txt` (стр. 175–176).
- Правила и числа:
  - Предупреждение: превышение пары постов в день может привести к блокировке аккаунта X (стр. 176).
  - При ошибках агенты настроены возвращать слово `FAILURE` (стр. 175–176).
- Ошибки и предупреждения: Проблема спама на YouTube; данный ABT создан только для демонстрации, а не для продакшена (стр. 175–176).
- Где нам пригодится: для запросов на автоматизацию мультиагентных цепочек с внешними API.

## 6.4 Building conversational autonomous multi-agents (стр. 177–178)
- Главная мысль — Комбинация изолированных деревьев (silos) и общих веток диалога (conversational threads) дает структурированность и постоянную обратную связь между агентами.
- Шаги процесса:
  1. Создать общий поток сообщений (thread) с помощью `api.create_thread()` (стр. 178).
  2. Запустить агента отладки кода (`Python Debugger`) на этом потоке (стр. 178).
  3. Подключить агента верификации (`Python Coding Assistant`) на тот же поток для проверки результата (стр. 178).
  4. Циклически запускать `tree.tick()` каждые 20 секунд до получения статуса `SUCCESS` и сохранения файла `fixed_bug.py` (стр. 178).
- Правила и числа: задержка (sleep) в цикле опроса составляет 20 секунд (стр. 178).
- Ошибки и предупреждения: Неправильное разделение ролей может привести к бесконечным циклам отладки; следите за условиями выхода `SUCCESS`/`FAILURE`.
- Где нам пригодится: для написания скриптов самоотладки кода силами двух агентов.

## 6.5 Building ABTs with back chaining (стр. 179–180)
- Главная мысль — «Обратная цепочка» (back chaining) — это метод логического проектирования деревьев поведения путем движения назад от конечной цели к начальным шагам.
- Шаги процесса:
  1. Определить целевое поведение (Goal behavior) (стр. 179).
  2. Определить необходимые действия (Required actions) (стр. 179).
  3. Выявить условия успешности (Conditions) (стр. 179).
  4. Определить режим связи (Коммуникация: изоляция или общие потоки) (стр. 179).
  5. Построить дерево рекурсивно снизу вверх (от цели к фактам) (стр. 179).
- Правила и числа:
  - Использование черной доски (blackboard) — хранилища ключ/значение для обмена данными между узлами (стр. 179).
  - Пример обратной цепочки для цели «Создать помощника для {task}» разворачивается в последовательность: инструкции -> имя -> тест -> проверка (condition) -> создание (стр. 179–180).
- Ошибки и предупреждения: На первом проходе держите инструкции общими; стремитесь создавать как можно меньше агентов (стр. 180).
- Где нам пригодится: для планирования структуры сложных скриптов и задач через запросы к LLM.

## 7.1 Introducing Nexus, not just another agent platform (стр. 184–188)
- Главная мысль — Nexus — это простая учебная платформа с открытым исходным кодом, написанная на Python и использующая Streamlit для создания интерфейса чата и управления агентами.
- Шаги процесса (установка в режиме разработки):
  1. Открыть терминал в папке `chapter_7`, создать виртуальное окружение Python 3.10 (стр. 187).
  2. Выполнить `git clone https://github.com/cxbxmxcx/Nexus.git` (стр. 187).
  3. Выполнить `pip install -e Nexus` (стр. 187).
  4. Задать переменную окружения `OPENAI_API_KEY` или записать ее в файл `.env` (стр. 186–187).
  5. Запустить приложение командой `nexus run` (стр. 186) или через отладку в VS Code.
- Правила и числа: Платформа использует порт `8501` по умолчанию (стр. 188).
- Ошибки и предупреждения: Если в браузере отключены куки, логиниться придется при каждом запуске (стр. 188).
- Где нам пригодится: как локальная база (платформа) для запуска собственных агентов и скриптов.

## 7.2 Introducing Streamlit for chat application development (стр. 189–194)
- Главная мысль — Streamlit позволяет быстро собирать современные веб-интерфейсы и чаты на чистом Python, используя сессионное состояние (`st.session_state`) и потоковую передачу данных (streaming).
- Шаги процесса (настройка дебага в VS Code):
  1. Нажать `Ctrl-Shift-D`, открыть или создать файл `.vscode/launch.json` (стр. 191).
  2. Указать тип `debugpy`, модуль `streamlit`, аргументы `["run", "${file}"]` (стр. 191).
  3. Нажать `F5` для запуска отладки текущего файла чата (стр. 192).
- Шаблоны и примеры:
  - Потоковый вывод ответа через OpenAI API: параметр `stream=True` и функция `st.write_stream(stream)` (стр. 193).
- Ошибки и предупреждения: Приложения Streamlit не имеют постоянной памяти (stateless) — весь скрипт перезапускается при любом клике; для сохранения истории нужен `st.session_state` или база данных (стр. 190).
- Где нам пригодится: для быстрого создания локальных веб-интерфейсов к нашим скриптам и базам данных.

## 7.3 Developing profiles and personas for agents (стр. 194–196)
- Главная мысль — Профили агентов в Nexus задаются через YAML-файлы в папке `nexus_profiles` и определяют системный промпт (личность/поведение) и доступные действия.
- Шаги процесса:
  1. Создать файл профиля, например `fiona.yaml`, в папке `Nexus/nexus/nexus_base/nexus_profiles` (стр. 195).
  2. Указать в нем имя, аватар, персонажа (`persona`), действия (`actions`) (стр. 195).
  3. Запустить Nexus через отладку в VS Code с аргументом `Nexus/nexus/streamlit_ui.py` (стр. 195).
- Шаблоны и примеры (файл `fiona.yaml`, стр. 195):
  ```yaml
  agentProfile:
    name: "Finona"
    avatar: "?"
    persona: "You are a very talkative AI..."
    actions:
      - search_wikipedia
  ```
- Ошибки и предупреждения: Поля `knowledge`, `memory`, `evaluators`, `planners`, `feedback` на текущий момент равны `null` и пока не поддерживаются (стр. 195).
- Где нам пригодится: для создания кастомных ролей агентов под конкретные задачи предпринимателя.

## 7.4 Powering the agent and understanding the agent engine (стр. 196–198)
- Главная мысль — Базовый класс `BaseAgent` задает абстрактный интерфейс, а конкретные движки (например, `OpenAIAgent`) реализуют запросы к API и управление историей сообщений.
- Шаги процесса:
  1. Создать подкласс от `BaseAgent` в папке `nexus_agents` (стр. 198).
  2. Реализовать обязательные методы: `get_response`, `get_semantic_response`, `get_response_stream`, `load_chat_history`, `load_actions` (стр. 197–198).
- Правила и числа: Температура генерации у OpenAI агента по умолчанию выставлена на `0.7` (стр. 198).
- Ошибки и предупреждения: Попытка вызвать нереализованные методы базового класса вызовет ошибку `NotImplementedError` (стр. 197).
- Где нам пригодится: для написания собственных движков под другие LLM (например, Claude или локальные модели).

## 7.5 Giving an agent actions and tools (стр. 198–202)
- Главная мысль — Инструменты и функции для агентов в Nexus создаются с помощью декоратора `@agent_action` в папке `nexus_actions`, автоматически генерируя спецификации инструментов для OpenAI.
- Шаги процесса:
  1. Написать функцию на Python (код или промпт) в файле папки `nexus_actions` (стр. 198).
  2. Добавить декоратор `@agent_action` (стр. 198).
  3. Добавить докстринг (`docstring`) — он автоматически превратится в описание инструмента для LLM (стр. 198–199).
- Шаблоны и примеры (стр. 194):
  - Нативная (кодовая) функция:
    ```python
    @agent_action
    def get_current_weather(location, unit="fahrenheit"):
        """Get the current weather in a given location"""
        return f"The current weather in {location} is 0 {unit}."
    ```
  - Семантическая (промпт-ориентированная) функция:
    ```python
    @agent_action
    def recommend(topic):
        """
        System: Provide a recommendation for a given {{topic}}.
        User: please provide a recommendation for {{topic}}.
        """
        pass
    ```
- Правила и числа: Движок OpenAI поддерживает параллельный вызов функций (`tool_calls`), выполняя их одновременно (стр. 200–201).
- Ошибки и предупреждения: Докстринг функции критически важен, так как из него извлекается описание для OpenAI API.
- Где нам пригодится: для быстрого превращения личных Python-скриптов в инструменты, доступные агентам.
