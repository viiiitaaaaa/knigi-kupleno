## 🛡️ Безопасность и защита агентов (Threat Modeling & Defense)
- **Главная мысль:** Агенты требуют многослойной защиты (layered defenses), так как обычных системных промптов недостаточно для сдерживания.
- **Что нужно знать/искать в книге:**
    - **Угрозы:** Косвенные инъекции промптов (indirect prompt injection), обход доверия (implicit trust bypass), эксплуатация доверия человека.
    - **Методы защиты:**
        1. **Изоляция:** Использование Docker для запуска кода, облачные песочницы (sandboxes), разделение исполнения и интерфейса (UI).
        2. **Принцип наименьших привилегий:** Ограничение прав агента по умолчанию.
        3. **LlamaFirewall:** Специализированный инструмент для семантической проверки, обнаружения невидимых символов и политики доверия для каждого вызова.
        4. **Red Teaming:** Тестирование агентов на проникновение и стресс-тесты через ролевые игры.
- **Где пригодится:** Проверка безопасности своих скриптов и защита данных при подключении внешних API.

## 🧠 Архитектура памяти (Memory Systems)
- **Главная мысль:** Память агента — это не просто лог чата, а многоуровневая система (топология), которая делает агента «опытным профессионалом».
- **Типы памяти:**
    - **Краткосрочная (Short-term):** Включая функции «путешествия во времени» (Time Travel) через `InMemorySaver`.
    - **Долгосрочная (Long-term):**
        - *Эпизодическая:* Опыт конкретных событий.
        - *Семантическая:* Общие знания и факты.
        - *Процедурная:* «Живое руководство» (living manual) — как выполнять задачи.
- **Гигиена памяти (Memory Hygiene):** Процесс очистки, сжатия записей и политики удержания данных, чтобы память оставалась релевантной и не переполняла контекст.
- **Где пригодится:** Создание «памяти» для личного помощника, чтобы он помнил контекст проектов между сессиями.

## ⚙️ Инфраструктура и оптимизация (Inference & Performance)
- **Главная мысль:** Эффективность агента зависит от физики развертывания (deployment physics) и управления ресурсами GPU.
- **Ключевые термины:**
    - **KV caching:** Кэширование ключей-значений для ускорения генерации (особенно важно при длинных контекстах).
    - **Cold Start (Холодный старт):** Задержка при первом запуске модели; решение через «масштабирование до нуля» (scaling to zero).
    - **vLLM, TGI, SGLang:** Движки для вывода (inference backends), которые нужно настраивать для пропускной способности.
    - **Квантование (Quantization):** Сжатие модели для работы на менее мощном железе.
- **Где пригодится:** Оптимизация затрат на облачные вычисления и ускорение работы своих скриптов.

## 🛠️ Управление данными и инструментами (MCP & Tooling)
- **Главная мысль:** Для надежности агент должен работать через строгие контракты данных, а не просто через текст.
- **Инструменты и методы:**
    - **MCP (Model Context Protocol):** «Универсальный пульт управления» для агентов, позволяющий им обнаруживать серверы и инструменты.
    - **Pydantic и Instructor:** Библиотеки для принуждения LLM выдавать строго структурированный JSON (избегание «ловушки хрупкого JSON»).
    - **Human-in-the-Loop (HITL):** Проектирование рабочих процессов, где человек подтверждает действие (approval gates), правит ответ или прерывает выполнение.
- **Где пригодится:** Написание надежных скриптов, которые не «ломаются» из-за изменения формата ответа ИИ.

## 🤖 Продвинутые парадигмы агентов (Agent Paradigms)
- **Главная мысль:** Переход от одного агента к системам (MAS — Multi-Agent Systems) через иерархии и рои.
- **Схемы организации:**
    - **Supervisor (Супервайзер):** Один главный агент управляет подчиненными.
    - **Swarm (Рой):** Группа агентов, взаимодействующих между собой.
    - **FSM/HSM:** Использование конечных и иерархических автоматов для управления состояниями агента (чтобы он не «забывал», на каком этапе задачи находится).
- **MCTS (Monte Carlo Tree Search):** Метод поиска в дереве возможностей для улучшения рассуждений (Reasoning) агента.
- **Где пригодится:** Построение сложных цепочек задач (например, исследование рынка $\rightarrow$ анализ $\rightarrow$ написание отчета).
