## Глава 1. Введение в агентов и их мир (стр. 36–37)
- Главная мысль — Агент — это сущность, которая автоматизирует взаимодействие с большой языковой моделью (LLM) для достижения результатов, принятия самостоятельных решений и выполнения сложных задач.
- Правила и числа — Нет конкретных числовых параметров (стр. 36–37).
- Шаблоны и примеры — Мультиагентные системы состоят из профилей агентов, работающих вместе под управлением прокси (стр. 36).
- Ошибки и предупреждения — Важно отличать автономных агентов от неавтономных, так как первые принимают независимые решения (стр. 36).
- Где нам пригодится — для понимания архитектуры запросов и проектирования памяти агентов.

## Глава 2. Использование возможностей больших языковых моделей (стр. 38–62)
- Главная мысль — Глава охватывает основы LLM (моделей на архитектуре GPT), работу с OpenAI API, запуск локальных моделей через LM Studio, техники промпт-инжиниринга и выбор оптимальной модели.
- Как делать:
  1. Установка пакетов для работы с API (стр. 41): `pip install openai python-dotenv`
  2. Запуск локального сервера LLM через LM Studio (стр. 23): выбрать модель, нажать «Start Server», подключиться по адресу `http://localhost:1234/v1`.
- Правила и числа — 
  - Температура (`temperature`) от 0 до 1: значение 0 дает максимально стабильный и детерминированный результат, 1.0 — максимальную вариативность (стр. 41–43).
  - Три роли в сообщениях чата: `system` (правила и контекст), `user` (запрос пользователя), `assistant` (история ответов) (стр. 42).
- Шаблоны и примеры — Пример кода Python для подключения к OpenAI API (`connecting.py`, стр. 41) и локальному серверу LM Studio (`lmstudio_server.py`, стр. 48). Стратегии промптинга: подробные запросы, назначение ролей (пишем от лица студента или инженера), использование разделителей (`'''` или теги `<statement>`), пошаговые инструкции, примеры (few-shot) и ограничение длины вывода (в словах или буллетах) (стр. 51–57).
- Ошибки и предупреждения — Неправильные настройки Server Model Settings в LM Studio вызовут ошибки соединения; следите за соответствием загруженной модели и настроек сервера (стр. 25).
- Где нам пригодится — для написания скриптов подключения к API, настройки локальных агентов и тестирования промптов.
