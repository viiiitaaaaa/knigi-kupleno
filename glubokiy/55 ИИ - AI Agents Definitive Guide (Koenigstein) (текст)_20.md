# Конспект раздела: Алфавитный указатель (Index)

## Обзор ключевых концепций (стр. текст без нумерации)
- **Главная мысль**: Список всех технических терминов, архитектурных паттернов и инструментов, используемых в книге для создания ИИ-агентов.

- **Основные блоки тем (по категориям из текста):**

    1. **Управление состоянием и памятью (State & Memory):**
        - *StateGraph, FSM/HSM*: использование конечных и иерархических автоматов для управления логикой агента.
        - *Memoizing*: кэширование переходов состояний для ускорения синтеза (Progress-Aware Synthesis).
        - *Thread IDs*: идентификаторы потоков для разделения контекста разных пользователей или задач.
        - *Time Travel*: возможность возврата к предыдущим снимкам состояния (checkpointing).

    2. **Архитектуры агентов (Agent Architectures):**
        - *Supervisor Architecture*: архитектура с «супервайзером» (главным агентом), который распределяет задачи между подчиненными.
        - *Swarm of Agents*: «рой» агентов для совместного решения задач.
        - *Deep Agents*: агенты, которые сначала планируют, а затем исполняют.
        - *ReAct*: цикл «Действие $\rightarrow$ Наблюдение $\rightarrow$ Размышление».

    3. **Инструменты и протоколы (Tools & MCP):**
        - *MCP (Model Context Protocol)*: универсальный интерфейс для подключения агентов к внешним серверам и данным.
        - *@tool decorator*: способ определения функций, которые LLM может вызывать.
        - *Sandboxed Python*: безопасное выполнение кода в изолированной среде.

    4. **Безопасность и тестирование (Defense & Testing):**
        - *Threat Modeling*: моделирование угроз, включая косвенные инъекции промптов.
        - *Red Teaming*: имитация атак для проверки устойчивости агента.
        - *LlamaFirewall*: компоненты защиты (guardrails) для фильтрации ввода/вывода.
        - *Behavioral Stress Testing*: ролевые игры для проверки поведения агента в стрессовых ситуациях.

    5. **Оптимизация и вывод (Inference & Optimization):**
        - *KV caching*: оптимизация памяти для повторного использования префиксов промптов.
        - *TGI (Text Generation Inference)*: бэкенд для генерации текста.
        - *MCTS (Monte Carlo Tree Search)*: поиск по дереву решений для сложных задач (баланс исследования и эксплуатации).

    6. **Оценка и метрики (Evaluation):**
        - *SWE-bench*: бенчмарк для оценки способности агентов решать задачи по программированию.
        - *Trajectory-based evaluation*: оценка не по финальному ответу, а по всему пути (траектории) рассуждений.

- **Ошибки и предупреждения**: 
    - Системные промпты не являются достаточным средством сдерживания (Tool Governance: System Prompts Aren’t Containment).

- **Где нам пригодится**: Для создания структуры базы знаний (Memory) в Claude, чтобы он мог быстро находить, какие методы (например, MCTS или MCP) применить к конкретной задаче предпринимателя.
