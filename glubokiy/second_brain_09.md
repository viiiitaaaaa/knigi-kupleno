## 1. Гибкость и метод CODE (стр. 209‑210)  
- **Главная мысль** – Система Second Brain — это набор инструментов, а не жёсткая идеология. Выбирайте и комбинируйте то, что вам резонирует, опираясь на четыре шага CODE: Capture (захват), Organize (организация), Distill (выделение сути), Express (выражение).  
- **Как делать**  
  1. Оцените, какие части методики вам подходят, а какие — нет; отбрасывайте ненужное.  
  2. При чувстве перегрузки сосредоточьтесь только на самых‑важных проектах и записях, поддерживающих их.  
  3. Не стройте всю систему сразу — продвигайте один проект через все четыре шага последовательно.  
  4. Если нужно, сосредоточьтесь только на одном из четырёх этапов (например, только Capture, если хотите лучше запоминать).  
- **Правила и числа**  
  - **4 шага** CODE (стр. 209).  
- **Шаблоны и примеры**  
  - Пример фокусировки: «Хотите помнить больше — развивайте Capture + Organize с помощью PARA».  
- **Ошибки и предупреждения**  
  - Ошибка — пытаться построить полностью всё сразу; вместо этого «один проект → четыре шага».  
  - Предупреждение — при перегрузке «отступите» и работайте только с текущими приоритетами.  
- **Где пригодится** – При построении запросов к ИИ‑помощнику: «Помоги пройти процесс CODE для проекта X», а также в структуре данных и автоматическом напоминании.

## 2. Двенадцать практических шагов для старта Second Brain (стр. 210‑211)  
- **Главная мысль** – Сразу после чтения книги можно начать применять системные привычки, внедряя 12 конкретных действий.  
- **Как делать**  

| № | Действие | Краткие шаги |
|---|----------|--------------|
| 1 | **Определить, что фиксировать** | 1) Представьте Second Brain как личный «commonplace book». 2) Выберите 2‑3 типа контента, которые уже цените. |
| 2 | **Выбрать приложение для заметок** | Скачайте бесплатный гид по актуальным приложениям (см. Buildingasecondbrain.com/resources). |
| 3 | **Выбрать инструмент захвата** | Начните с «read‑later»‑приложения, сохраняйте статьи/контент для последующего чтения. |
| 4 | **Настроить PARA** | Создайте четыре папки — Projects, Areas, Resources, Archives; добавьте папку/тег для каждого активного проекта. |
| 5 | **Составить список «12 любимых проблем»** | Запишите 12 вопросов/проблем, которые вам интересны; используйте их как фильтр при отборе контента. |
| 6 | **Автоматически захватывать выделения из e‑книг** | Подключите бесплатную интеграцию (см. рекомендации на Buildingasecondbrain.com/resources). |
| 7 | **Практиковать Progressive Summarization** | На наборе заметок по текущему проекту применяйте многоуровневое выделение (highlighting). |
| 8 | **Создать один Intermediate Packet** | Выберите небольшой, конкретный элемент проекта (промо‑презентация, таблица, план встречи) и сделайте первый вариант. |
| 9 | **Сделать прогресс по одной доставляемой части** | Примените техники Express (Archipelago of Ideas, Hemingway Bridge, Dial Down the Scope), используя только свои заметки. |
| 10| **Запланировать Weekly Review** | Добавьте повторяющуюся встречу с собой; начните с очистки «inbox» заметок и постановки приоритетов недели. |
| 11| **Оценить уровень ноттения** | Пройдите бесплатный тест на Buildingasecondbrain.com/quiz. |
| 12| **Вступить в PKM‑сообщество** | Подпишитесь на #PKM, #SecondBrain, #BASB в Twitter, LinkedIn, Substack, Medium; делитесь ключевыми выводами. |

- **Правила и числа**  
  - **12 практических шагов** (стр. 210‑211).  
  - **4 папки** PARA (стр. 210).  
- **Шаблоны и примеры**  
  - Шаблон «12 любимых проблем» — список вопросов, который можно хранить как отдельную заметку.  
  - Пример Intermediate Packet — бизнес‑пропозиция, схема, план мероприятия, темы встречи.  
- **Ошибки и предупреждения**  
  - Не пытайтесь сразу охватить всё: «один проект → один Intermediate Packet».  
  - При отсутствии привычки к нотированию сначала настройте «read‑later»‑приложение, иначе будете терять контент.  
- **Где пригодится** – Быстрый запуск привычек в ваших скриптах/агентах: автоматический импорт выделений, планирование weekly‑review, проверка соответствия шаблону PARA.

## 3. Жизненный путь Second Brain (стр. 212‑213)  
- **Главная мысль** – Создание Second Brain — это конечный проект, но его использование — постоянная практика. Периодический пересмотр (re‑read) помогает обнаружить упущенное и сформировать новую идентичность, управляя своим вниманием и энергией.  
- **Как делать**  
  1. Периодически (через несколько месяцев) возвращайтесь к «Building a Second Brain», чтобы увидеть недочёты.  
  2. Выбирайте, какой из шагов CODE хотите усилить (Capture, Organize, Distill, Express) в зависимости от текущих целей.  
- **Правила и числа** – Нет новых цифр, но упоминается **«один проект → четыре шага»** как проверенный подход (стр. 209).  
- **Шаблоны и примеры** – Нет конкретных шаблонов, лишь метафора «жизненный путь», «идентичность».  
- **Ошибки и предупреждения** – Не воспринимайте систему как «одноразовый» набор; без регулярных ревизий она теряет эффективность.  
- **Где пригодится** – При построении долгосрочных целей в планировщике, в диалогах с ИИ о переоценке проекта и личных приоритетов.

## 4. Бонус‑главa: Как создать работающую систему тегов (стр. 214‑215)  
- **Главная мысль** – Теги — дополнительный слой организации, построенный на принципе «actionability» (польза для действий). Они не обязательны для старта, но полезны при росте коллекции знаний.  
- **Как делать**  
  1. Выделите категории, которые сразу позволяют выполнить действие (например, «срочно‑отправить», «для рефери», «для вдохновения»).  
  2. Присваивайте тег только если он делает заметку более полезной в работе.  
- **Правила и числа** – Принцип **actionability** (страница 214).  
- **Шаблоны и примеры** – Пример тегов: *#ProjectX‑Review*, *#Idea‑To‑Prototype*, *#Read‑Later*.  
- **Ошибки и предупреждения** – Избегайте «тег‑захлебывания»: слишком много тегов убивает их действие.  
- **Где пригодится** – В запросах к автоматическим классификаторам, в фильтрации в поиске, в построении быстрых представлений для агентов.
